# media/

Drop a short screen recording of the deployed app here as `demo.gif`
(about 30 seconds, under ~5 MB). It is referenced from the main `README.md`.

How to make one on Windows:

1. Install [ScreenToGif](https://www.screentogif.com/) (free, open source).
2. Open the deployed app at <https://text2queryagent.streamlit.app>.
3. Record yourself clicking a couple of the "Try these" prompts and answering
   a follow-up question.
4. Save the recording as `demo.gif` in this folder (trim to ~30s).
